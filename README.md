# 마사지 지역 플랫폼 (그누보드5 테마 + 플러그인)

서울 · 경기 · 인천의 **행정구 77곳**과 **대표 행정동 231곳**을 기준으로
로드샵 · 출장마사지 · 홈타이 정보를 안내하는 지역 디렉터리입니다.
그누보드5에 얹는 **플러그인 + 테마** 구조이며, 이미지는 전부 **텍스트 기반 인라인 SVG**로 생성됩니다.

---

## 지금 바로 화면 보기

```
preview/index.html   ← 브라우저로 열면 됩니다 (웹서버 불필요)
```

기본 프리뷰는 **서울 강남구·마포구, 경기 성남시 분당구, 인천 연수구**와
해당 대표 행정동·업소까지 74페이지가 들어 있습니다. 전체(1,200여 페이지)는 아래 명령으로 생성합니다.

```bash
php tools/build_preview.php --all
```

프리뷰는 그누보드5 런타임과 **같은 템플릿·라이브러리**를 호출하므로,
여기서 보이는 화면이 실제 서비스 화면과 동일합니다.

## 설치 요약

1. `g5/plugin/kkuk` → 그누보드5의 `/plugin/kkuk`
2. `g5/theme/kkuk-care` → 그누보드5의 `/theme/kkuk-care` (관리자에서 테마 선택)
3. `g5/htaccess-sample.txt` 내용을 루트 `.htaccess`에 추가
4. `/plugin/kkuk/install.php` 접속 (최고관리자) → 테이블 생성 + 데이터 적재 → **파일 삭제**
5. `_common.php`에서 상호 · 도메인 · 사업자 정보 입력

자세한 내용은 [docs/01-설치가이드.md](docs/01-설치가이드.md).

## ⚠ 공개 전에 반드시 할 일

현재 업소 정보는 **전부 가상 데이터**입니다. 그래서 기본값으로 **검색엔진 색인이 막혀 있습니다.**

- `_common.php` → `KKUK_DEMO_DATA = true` 인 동안 모든 페이지에 `noindex`, `robots.txt`는 전체 차단
- 실제 업체 정보로 교체한 뒤에만 `false` 로 변경
- 평점/후기 구조화 데이터(`aggregateRating`)는 `KKUK_SCHEMA_RATING = false` 로 꺼져 있습니다.
  실제 후기가 쌓이기 전에 켜면 구조화 데이터 위반입니다.

가상 데이터가 색인되는 것 자체가 저품질 · 스팸 신호가 되므로, 이 두 스위치는 안전장치입니다.
전체 목록은 [docs/04-운영-체크리스트.md](docs/04-운영-체크리스트.md).
