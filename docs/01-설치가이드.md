# 01. 설치 가이드

## 0. 준비물

| 항목 | 요구 사항 |
|---|---|
| 그누보드 | 5.4 이상 |
| PHP | 7.4 이상 (8.x 권장 — 개발·검증은 PHP 8.3) |
| 웹서버 | Apache(mod_rewrite) 또는 Nginx |
| DB | MySQL 5.7 / MariaDB 10 이상 (DB 모드로 운영할 때만) |

---

## 1. 파일 배치

```
그누보드루트/
├─ plugin/kkuk/          ←  g5/plugin/kkuk  전체 복사
└─ theme/kkuk-care/      ←  g5/theme/kkuk-care  전체 복사
```

업로드 후 권한을 확인합니다. 플러그인은 쓰기를 하지 않으므로 `644 / 755` 로 충분합니다.

---

## 2. 리라이트 설정

`g5/htaccess-sample.txt` 의 내용을 그누보드 루트 `.htaccess` 에 추가합니다.
기존 `.htaccess` 가 있으면 **맨 아래**에 붙여 넣으세요.

Nginx 는 같은 파일 하단의 주석 블록을 `server { }` 안에 넣습니다.

> 리라이트를 쓸 수 없는 환경이라면 `/plugin/kkuk/index.php?r=seoul/gangnam` 형태로도 동작합니다.
> 다만 주소가 길어져 SEO 에 불리하므로 가능하면 리라이트를 권장합니다.

---

## 3. 테마 적용

그누보드 관리자 → **환경설정 → 테마** 에서 `kkuk-care` 선택.

테마는 게시판·회원가입 등 그누보드 기본 페이지의 "껍데기"만 담당합니다.
지역/업소 페이지는 플러그인이 문서 전체를 직접 그리므로, **다른 테마를 쓰더라도 플러그인은 그대로 동작**합니다.

---

## 4. 설치 스크립트 실행

최고관리자로 로그인한 상태에서 접속합니다.

```
https://도메인/plugin/kkuk/install.php
```

하는 일

1. `g5_kkuk_region`, `g5_kkuk_shop` 테이블 생성
2. `data/regions.php`, `data/shops.php` 내용을 테이블에 적재

> **실행 후 `install.php` 는 반드시 삭제**하거나 접근을 차단하세요.

파일 기반만으로도 사이트는 정상 동작합니다. DB 적재는 관리자 화면에서 업소를 직접 추가·수정하려는 경우에만 필요합니다.

## 5. 기본 설정값 변경

`plugin/kkuk/_common.php` 상단에서 한 번에 바꿉니다.

```php
define('KKUK_BRAND',     '마사지 지역가이드');   // 상호 (확정 후 교체)
define('KKUK_BRAND_SUB', '서울 · 경기 · 인천');
define('KKUK_BASE',      'https://kkuk-ary.pages.dev'); // 실제 도메인
define('KKUK_TEL',       '050842603302');         // 고정
define('KKUK_TEL_FMT',   '0508-4260-3302');
define('KKUK_TEL_LABEL', '출장마사지');          // 전화 버튼 문구
define('KKUK_BIZ_NAME',  '(상호 미정)');          // 사업자 정보 (표기 의무)
define('KKUK_BIZ_OWNER', '(대표자명)');
define('KKUK_BIZ_NO',    '(사업자등록번호)');
define('KKUK_BIZ_ADDR',  '(사업장 주소)');
define('KKUK_NAVER_VERIFY', '');                 // 서치어드바이저 소유확인
define('KKUK_GSC_VERIFY',   '');                 // 서치콘솔 소유확인
```

색인 정책 스위치는 `lib/seo.lib.php` 상단에 있습니다. 기본값을 바꾸려면
`_common.php` 에서 먼저 `define` 하면 됩니다.

```php
define('KKUK_DEMO_DATA',     false);  // 실제 업소 데이터로 교체한 뒤에만 false
define('KKUK_SCHEMA_RATING', false);  // 실제 후기가 쌓인 뒤에만 true
```

## 6. 데이터 수정 방법

### 지역을 추가·수정하려면

`tools/seed/seoul.php`, `gyeonggi.php`, `incheon.php` 를 고친 뒤 다시 생성합니다.

```bash
php tools/gen_data.php
```

시드 포맷(구)

```
이름|슬러그|위도|경도|노선|주요역|랜드마크|상권성격|인접지역|한줄특성|상위시(일반구만)
```

시드 포맷(동)

```
이름|슬러그|성격코드|앵커(최대3)
```

성격 코드

| 코드 | 의미 | 코드 | 의미 |
|---|---|---|---|
| `st` | 역세권 상권 | `nt` | 신도시 · 택지 |
| `ap` | 대단지 주거 | `ind` | 산업 · 공단 |
| `uni` | 대학 · 학원가 | `tr` | 관광 · 휴양 |
| `of` | 오피스 업무 | `rs` | 단독주택가 |
| `md` | 전통시장 · 구도심 | `mixed` | 주상 복합 |

> 좌표는 구청 소재지 기준 **근사값**입니다. 동 좌표는 구 좌표에 ±0.012° 오프셋을 준 값이므로,
> 지도 서비스와 연동하거나 로컬 검색 정확도를 올리려면 실측 좌표로 교체하세요.

### 업소를 실제 정보로 교체하려면

둘 중 하나를 고릅니다.

1. **DB 모드** — `install.php` 실행 후 `g5_kkuk_shop` 테이블을 직접 관리
2. **파일 모드** — `tools/seed/shop_words.php` 를 수정하고 `php tools/gen_data.php` 재실행

실제 운영은 1번(DB 모드)을 권장합니다. 업소마다 사진·휴무일·실제 주소 같은 항목이 늘어나기 때문입니다.

## 7. 검증

```bash
php tools/gen_data.php        # 데이터 재생성 + 키워드 누락 검사
php tools/check_dup.php       # 본문 길이 · 중복 유사도 검사
php tools/build_preview.php   # 정적 프리뷰 (디자인 확인)
```

`gen_data.php` 는 실행할 때마다 **로드샵·스파 디스크립션의 `출장 마사지` / `홈타이` 키워드 누락 건수**를 출력합니다.
이 값이 0이 아니면 템플릿을 확인하세요.
