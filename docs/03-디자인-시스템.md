# 03. 디자인 시스템

## 설계 전제

같은 업종 사이트 대부분이 **검정 바탕 + 네온 핑크/퍼플 + 큰 사진**을 씁니다.
그 문법을 그대로 따르면 (1) 이전 플랫폼과 유사해 보이고 (2) 시인성이 떨어집니다.
그래서 네 가지를 의도적으로 반대로 잡았습니다.

| 관행 | 이 프로젝트 |
|---|---|
| 다크 퍼스트 | **라이트 퍼스트** (다크는 토글·시스템 설정으로 지원) |
| 네온 그라데이션 | **단색 + 실선 테두리 + 오프셋 그림자** (편집 디자인 문법) |
| 사진 중심 | **텍스트 SVG 중심** (로딩 빠름, 저작권 문제 없음, 지역마다 다른 그림) |
| 얇고 작은 글씨 | **본문 17px · 행간 1.78 · 대비 AA 이상** |

---

## 1. 색 토큰

`asset/kkuk.css` 의 `:root` 한 곳에서 관리합니다.

```
지면   --paper #FBF8F3   --surface #FFFFFF   --surface-2 #F3EEE5
글자   --ink #16130F     --ink-2 #4C443A     --ink-3 #6E6458
선     --line #DED5C6    --line-strong #1C1813
브랜드 --brand #0B6257  (딥 티크 그린)
강조   --accent #A8411A (번트 테라코타)
```

대비비 (WCAG 기준, 4.5:1 이상이 AA)

| 조합 | 대비 | 판정 |
|---|---|---|
| `--ink` on `--paper` | 15.8 : 1 | AAA |
| `--ink-2` on `--paper` | 8.3 : 1 | AAA |
| `--ink-3` on `--paper` | 5.3 : 1 | AA (14px 이상에만 사용) |
| `--brand` on `#fff` | 6.4 : 1 | AA |
| `--accent` on `#fff` | 6.1 : 1 | AA |
| `#fff` on `--accent` | 6.1 : 1 | AA — 전화 버튼 |

다크 모드는 `prefers-color-scheme` + `data-theme` 수동 토글을 모두 지원하고,
선택값은 `localStorage` 에 저장됩니다. `<head>` 인라인 스크립트로 깜빡임(FOUC)을 막습니다.

---

## 2. 타이포그래피

- 서체 : **Pretendard Variable** (dynamic subset CDN) → 시스템 한글 폰트 폴백
- 본문 17px / 행간 1.78 / 자간 -0.011em / `word-break: keep-all`
  - 한글은 영문보다 행간이 넓어야 읽힙니다. 1.6 이하는 뭉쳐 보입니다.
  - `keep-all` 로 단어 중간이 끊기지 않게 합니다.
- 제목 : `clamp()` 기반 유동 크기, 자간 -0.025 ~ -0.045em
- 숫자 : `font-variant-numeric: tabular-nums` — 가격·전화번호가 흔들리지 않음

## 3. 컴포넌트

| 클래스 | 용도 | 비고 |
|---|---|---|
| `.k-card` | 공통 카드 | 2px 실선 + 3px 오프셋 그림자, hover 시 2px 이동 |
| `.k-shop` | 업소 카드 | 썸네일(16:9) · 본문 · 하단 가격/평점 |
| `.k-chip` | 지역 칩 | 최소 높이 44px, 선택 시 브랜드 색 반전 |
| `.k-hero__box` | 히어로 | 인라인 SVG, 높이 `clamp(236px, 26vw, 372px)` |
| `.k-article` | 본문 | h2 좌측 색막대, 강조는 밑줄 하이라이트 |
| `.k-faq` | 질문 아코디언 | `<details>` 기반 — JS 없이도 동작 |
| `.k-callbar` | 모바일 전화 바 | 아래 4번 참고 |
| `.k-panel` | 사이드 예약 패널 | 1000px 이상에서 sticky |

접근성

- 모든 탭 영역 최소 44px, 주요 CTA 58px 이상
- `:focus-visible` 에 3px 파란 아웃라인
- "본문으로 바로가기" 스킵 링크
- 필터 결과는 `aria-live` 로 알림
- `prefers-reduced-motion` 에서 모든 전환 제거
- 인쇄 시 헤더·전화바·푸터 숨김

## 4. 모바일 고정 전화연결 바

요청하신 핵심 사양이라 별도로 정리합니다.

```
┌──────────────────────────────────────────────┬────────┐
│ 📞  출장마사지 · 홈타이 24시 상담             │  💬    │
│     전화연결  050-8202-4749                  │ 이용안내│
└──────────────────────────────────────────────┴────────┘
```

| 항목 | 값 |
|---|---|
| 노출 조건 | `max-width: 860px` |
| 높이 | 58px 이상 (실제 탭 영역) |
| 하단 여백 | `calc(10px + env(safe-area-inset-bottom))` — 아이폰 홈바 대응 |
| 본문 가림 방지 | `body { padding-bottom: 84px }` |
| 1행 | `출장마사지 · 홈타이 24시 상담` (넘치면 말줄임) |
| 2행 | `전화연결 050-8202-4749` — 320px 이하에서는 `전화연결` 접두어만 숨김 |
| 링크 | `tel:05082024749` |
| 접근성 | `aria-label="출장마사지 전화연결 050-8202-4749"` |
| 전환 집계 | 클릭 시 GA4 `call_click` + 네이버 애널리틱스 + `kkuk:call` 커스텀 이벤트 |

검증 완료 화면 폭 : **320px / 390px / 430px** — 모두 번호 잘림 없음.

## 5. 텍스트 SVG 생성

래스터 이미지를 전혀 쓰지 않습니다. `lib/svg.lib.php` 가 전부 생성합니다.

### 히어로박스

- 뷰박스 `1200×420`, `preserveAspectRatio="xMidYMid slice"` → 좁은 화면에서는 좌우를 잘라냄
- 구성 : 상단 배지(시도·구) → 대형 제목 → 구분선 → 부제 → 키워드 칩 → 하단 보조문
- **팔레트 14종 × 장식 5종 = 70가지 조합**, 슬러그 해시로 결정
  → 지역마다 다른 그림, 같은 지역은 항상 같은 그림(캐시·스냅샷 안정)
- 모든 팔레트가 어두운 배경 + 밝은 글자 → 밝은 지면과 확실히 분리

### 업소 썸네일

- 뷰박스 `800×450` (16:9)
- 구성 : 모노그램(상호 앞 2글자) → 상호 → 구분선 → 동 이름
- 카드 본문이 업종·지역을 이미 표기하므로 **SVG 에서는 중복 정보를 뺐습니다**

### 아이콘

`kkuk_icon()` 으로 phone / pin / clock / star / chat / sun / route / check 제공.
`currentColor` 를 상속하므로 다크 모드에서 자동으로 색이 맞습니다.

---

## 6. 성능

- 외부 리소스는 **웹폰트 CSS 1개**뿐 (JS 라이브러리 0, jQuery 비의존)
- `kkuk.css` 20KB · `kkuk.js` 4KB (압축 전)
- 이미지 요청 0건 — 모든 그림이 HTML 안에 인라인
- 그누보드5 의 jQuery 와 충돌하지 않도록 전역 변수를 만들지 않음 (IIFE + 이벤트 위임)
