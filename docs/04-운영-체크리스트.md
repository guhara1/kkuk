# 04. 공개 전 체크리스트

## A. 반드시 처리 (안 하면 위험)

- [ ] **가상 업소 908곳을 실제 정보로 교체**
      현재 상호·설명·가격·평점은 전부 생성된 더미입니다.
- [ ] 교체 후 `_common.php` 에 `define('KKUK_DEMO_DATA', false);` 추가
      → 이 전에는 전 페이지 `noindex` + `robots.txt` 전체 차단 상태입니다.
- [ ] `KKUK_BASE` 를 실제 도메인으로 변경 (canonical · 사이트맵 절대경로에 사용)
- [ ] `KKUK_BRAND` 상호 확정값 입력
- [ ] 사업자 정보 4종 입력 (`KKUK_BIZ_NAME` / `OWNER` / `NO` / `ADDR`)
      — 전자상거래법·정보통신망법상 표기 의무
- [ ] `/plugin/kkuk/install.php` **삭제** 또는 접근 차단
- [ ] 평점·후기를 실제로 수집하기 전까지 `KKUK_SCHEMA_RATING` 은 `false` 유지
      (없는 후기로 `aggregateRating` 을 내보내면 구조화 데이터 위반 → 수동 조치 대상)

## B. 정확도 보정

- [ ] 구 좌표 77개를 실측값으로 교체 (현재 구청 소재지 근사값)
- [ ] 동 좌표 231개를 실측값으로 교체 (현재 구 좌표 ± 0.012° 오프셋)
- [ ] 각 동의 앵커(역·시장·공원)가 현재도 유효한지 확인
      — 역 이름 변경, 시장 폐업 등이 잦습니다
- [ ] 옹진군·강화군 등 도서/농촌 지역의 실제 운영 가능 여부 확인
      (현재 옹진군은 로드샵 없이 출장·홈타이만 배치)

## C. 검색엔진 등록

- [ ] 네이버 서치어드바이저 등록 → 소유확인 → `KKUK_NAVER_VERIFY`
- [ ] 사이트맵 `/sitemap.xml` 제출
- [ ] RSS `/rss.xml` 제출
- [ ] 구글 서치콘솔 등록 → `KKUK_GSC_VERIFY`
- [ ] 네이버 스마트플레이스 등록 (지역 업체 유입의 핵심)
- [ ] GA4 설치 → `call_click` 이벤트를 전환으로 설정

## D. 이전 플랫폼과의 분리 확인

- [ ] 이전 사이트에서 복사한 문장이 하나도 없는지
- [ ] `<title>` / 메타 설명 패턴이 겹치지 않는지
- [ ] 상호·브랜드가 명확히 다른지
- [ ] `php tools/check_dup.php` 결과가 **최대 0.30 미만**인지
- [ ] 두 사이트가 같은 전화번호를 쓴다면, 그 사실이 주는 위험을 감수할지 판단
      (검색엔진은 같은 연락처를 같은 출처로 묶어 볼 수 있습니다)

## E. 법적·표기 사항

- [ ] 푸터의 "의료 행위가 아님" 고지 유지
      — 마사지업 광고에서 치료·의학적 효과를 주장하면 의료법 위반 소지
- [ ] "건전 영업" 고지 유지, 19세 미만 이용 불가 표기
- [ ] 과장 표현(최고/1위/완치/특효) 사용 금지
- [ ] 가격 표시는 **총액 기준**으로 (추가 요금 숨기면 전자상거래법 문제)
- [ ] 후기를 게시할 경우 실제 이용자 작성분만 — 창작 후기는 표시광고법 위반

## F. 공개 후 운영

- [ ] 구 단위로 나눠 점진적 색인 요청 (한 번에 1,200페이지 요청 금지)
- [ ] 2~8주간 페이지 구조를 바꾸지 않기 (평가 초기화 방지)
- [ ] 업소 추가 시 해당 동 본문의 등록 수가 자동 반영되는지 확인
- [ ] 월 1회 `php tools/check_dup.php` 로 유사도 재점검
- [ ] 전화 전환율을 지역별로 확인 → 수요가 높은 구부터 콘텐츠 보강

## 자주 하게 될 명령

```bash
php tools/gen_data.php                 # 시드 수정 후 데이터 재생성
php tools/check_dup.php --top 20       # 본문 길이 · 유사도 검사
php tools/build_preview.php            # 샘플 프리뷰 (74페이지)
php tools/build_preview.php --all      # 전체 프리뷰 (1,200여 페이지)
```
